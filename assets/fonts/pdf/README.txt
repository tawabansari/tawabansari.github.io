These are TrueType containers converted from the site's existing Vazirmatn Regular
and Bold WOFF2 files with fontTools 4.66.1 (`TTFont`, `flavor = None`, `save`).
Glyphs, shaping tables, names, and font metrics are unchanged. React PDF's font
subsetter requires the TrueType format. They are loaded only for local PDF export.
