Qur'anic Root

Qur'anic Root SH Q Q

Splitting, cracking, and opening within something hard

Short Note

This page is a placeholder so verse links to the root SH Q Q have a destination. The full study of this root will be written later.

In Al-Baqarah 2:74, this root shows that even hard stone can split open and become a path for water to come out.
